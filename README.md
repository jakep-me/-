# Silent Arena FPS (무음 FPS)

엄청 복잡하고 재미있지만 **소리가 없는** 브라우저 FPS 게임입니다.

## 실행 방법

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 조작

- `WASD`: 이동
- `좌클릭`: 사격
- `F`: 재장전
- `Q`: Pulse (근거리 충격파)
- `E`: Dash (고속 이동)
- `R`: Time-Slow (적 시간 감속)

## 특징

- 레이캐스팅 기반 의사 3D 렌더링
- 웨이브 기반 적 스폰 (스카웃/팬텀/브루트)
- 쉴드/탄약 드랍과 자원 관리
- 미니맵 + 크로스헤어 + HUD
- 사운드 API 미사용 (완전 무음)

# Neon Strike Mobile

모바일에서 플레이하는 전술 FPS 감성을 목표로 만든 단일 페이지 웹 게임 프로토타입입니다.

## 특징

- 왼쪽 이동 패드 + 오른쪽 조준 패드 기반의 모바일 FPS 조작
- 사격 / 재장전 / 대시 / 스모크 버튼이 있는 전술형 전투 루프
- 웨이브가 증가할수록 적 수와 속도가 함께 올라가는 생존형 진행
- 설치 없이 `index.html`만 열어도 실행 가능한 순수 HTML/CSS/JS 구성

## 실행 방법

별도 빌드가 필요 없습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`를 열면 바로 플레이할 수 있습니다.

## 조작

### 모바일

- 왼쪽 패드: 이동
- 오른쪽 패드: 조준
- 사격 버튼: 연사
- 대시 버튼: 순간 회피
- 스모크 버튼: 적 둔화
- 재장전 버튼: 탄창 재장전

### 키보드 / 마우스 테스트

- `WASD`: 이동
- 마우스: 조준
- `Space`: 사격
- `R`: 재장전
- `Q`: 대시
- `E`: 스모크
- `P`: 일시정지
